01 · INGESTION & CHUNKING PIPELINE

817 Docs → 3,328 Contextual Chunks (178s)

  • RST .. include:: expansion: Inlines shared fragments (up to depth 3) into the parent page and skips standalone fragments (+0.04 MRR).
  • Heading-aware chunking: Parses Markdown & RST section trees, packs small siblings up to 400 tokens (48 overlap), and prepends Title > Section breadcrumbs.
  • Idempotent & atomic: SHA-256 content hash skips unchanged files (re-ingest in ~2s); changed files replace chunks via binary COPY in one transaction.

02 · HYBRID RETRIEVAL & RERANKING

HNSW + GIN Full-Text → RRF → Cross-Encoder

  • Vector branch: bge-small-en-v1.5 (384-d) with HNSW cosine index (ef_search=100, relaxed_order iterative scan).
  • Keyword branch: Weighted Postgres tsvector (A heading, B content) + GIN index catches exact config identifiers like max_connections.
  • RRF + Rerank: Top 60 from each branch fused via 1/(60+rank); top 20 scored by ms-marco-MiniLM-L-6-v2 → hit@1 0.81, hit@5 1.00, MRR 0.89.

03 · CAPACITY, SCALE & GUARDRAILS

Measured Limits & Production Controls

  • Memory gate: BoundedSemaphore(1) caps concurrent ONNX activations, cutting 16-client RSS from 9.8 GB to 1.2 GB.
  • Latency profile: 603ms p50 (1.6 req/s) with reranker; 30ms p50 (46 req/s) with reranker disabled.
